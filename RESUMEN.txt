┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. SISTEMA DE LOGGING MULTI-NIVEL                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✓ 3 archivos de log separados por propósito:                               │
│   • events.log   - Solo eventos de negocio                                 │
│   • error.log    - Solo errores y excepciones                              │
│   • app.log      - Todo (debug, info, warnings, errors)                    │
│                                                                             │
│ ✓ Rotación automática (10 MB × 10 archivos = 100 MB historial)            │
│ ✓ Formato estructurado y legible                                           │
│ ✓ Timestamps precisos en cada evento                                       │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. EVENTOS DE NEGOCIO RASTREABLES                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✓ 8 tipos de eventos automáticamente registrados:                          │
│   • USER_CREATED     - Usuario registrado                                  │
│   • USER_UPDATED     - Usuario actualizado (con detalles de cambios)       │
│   • USER_DELETED     - Usuario eliminado                                   │
│   • TASK_CREATED     - Tarea creada                                        │
│   • TASK_UPDATED     - Tarea actualizada (con detalles de cambios)         │
│   • TASK_COMPLETED   - Tarea completada                                    │
│   • TASK_DELETED     - Tarea eliminada                                     │
│   • TASKS_CLEARED    - Tareas completadas limpiadas                        │
│                                                                             │
│ ✓ Cada evento incluye contexto completo (IDs, campos modificados, etc.)   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. LOGGING DE PETICIONES HTTP                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✓ Todas las peticiones registradas automáticamente:                        │
│   • Método HTTP (GET, POST, PUT, DELETE)                                   │
│   • Path y query parameters                                                │
│   • IP del cliente (incluye X-Forwarded-For)                               │
│   • Status code de respuesta                                               │
│                                                                             │
│ ✓ Middleware integrado (@app.before_request / @app.after_request)         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. HERRAMIENTA DE VISUALIZACIÓN                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✓ Script Python: view_logs.py                                              │
│   • python view_logs.py events           → Ver eventos                     │
│   • python view_logs.py errors           → Ver errores                     │
│   • python view_logs.py all              → Ver todo                        │
│   • python view_logs.py events --follow  → Tiempo real                     │
│   • python view_logs.py stats            → Estadísticas                    │
│                                                                             │
│ ✓ Script de prueba: test_logs.ps1 (simula actividad automáticamente)      │

                        💡 COMANDOS MÁS ÚTILES
═══════════════════════════════════════════════════════════════════════════════

DESARROLLO:
  python app.py                              Ejecutar aplicación
  python view_logs.py events --follow        Ver logs en tiempo real
  powershell -File test_logs.ps1             Simular actividad

PRODUCCIÓN (EC2):
  sudo supervisorctl restart flask-app       Reiniciar aplicación
  sudo systemctl restart nginx               Reiniciar Nginx
  tail -f ~/app_python/logs/events.log       Ver logs de eventos

BÚSQUEDA EN LOGS:
  grep "USER_CREATED" logs/events.log        Usuarios creados
  grep "TASK_COMPLETED" logs/events.log      Tareas completadas
  tail -50 logs/error.log                    Últimos 50 errores
